# docsgrep Tooling Documentation

This directory contains detailed documentation for each tool available in the **docsgrep** MCP server.

## Tool Index

### Discovery & Setup
- [🏕️ `setup_camp`](tools/setup_camp.md) - Initialize workspace and .gitignore.
- [🕵️ `spy_stack`](tools/spy_stack.md) - Analyze project technology stack.
- [🐕 `sniff_style`](tools/sniff_style.md) - Detect coding conventions and patterns.
- [🔍 `hunt_docs`](tools/hunt_docs.md) - Discover READMEs and documentation folders.
- [🚚 `fetch_repo`](tools/fetch_repo.md) - Clone and analyze remote repositories.

### Content & Search
- [👀 `peek_file`](tools/peek_file.md) - Read documentation file contents safely.
- [🔎 `grep_docs`](tools/grep_docs.md) - Regex search within documentation.
- [🧠 `fathom_meaning`](tools/fathom_meaning.md) - Semantic/natural language search.
- [📝 `tldr_docs`](tools/tldr_docs.md) - Concise documentation summarization.

### Auditing & Quality
- [🧼 `lint_code`](tools/lint_code.md) - Enterprise-grade code quality audit.
- [🛡️ `guard_security`](tools/guard_security.md) - OWASP, secrets, and privacy audit.
- [🐛 `catch_bugs`](tools/catch_bugs.md) - Detect runtime errors and logic flaws.
- [❓ `ask_lint`](tools/ask_lint.md) - Interactive prompt for linting options.
- [❓ `ask_guard`](tools/ask_guard.md) - Interactive prompt for security options.

### Maintenance & Sync
- [👃 `smell_stale`](tools/smell_stale.md) - Identify outdated or out-of-sync docs.
- [📏 `gauge_docs`](tools/gauge_docs.md) - Measure docblock coverage in source code.
- [🔄 `sync_docs`](tools/sync_docs.md) - Update documentation based on code changes.
- [✅ `verify_truth`](tools/verify_truth.md) - Verify doc accuracy against source code.
- [📊 `spot_delta`](tools/spot_delta.md) - Detail differences between docs and code.
- [🦴 `catch_fossils`](tools/catch_fossils.md) - Prioritize doc updates based on git history.

### Context & Help
- [🧭 `sense_surroundings`](tools/sense_surroundings.md) - Proactive context for current task.
- [📚 `doc_the_tools`](tools/doc_the_tools.md) - Comprehensive in-app help for docsgrep.
- [🧹 `purge_cache`](tools/purge_cache.md) - Clean up old cached repositories.

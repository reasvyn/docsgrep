# Contributing to @anovise/docsgrep

First off, thank you for considering contributing to `@anovise/docsgrep`! It's people like you that make open source such a great community.

## Where do I go from here?

If you've noticed a bug or have a feature request, please open an issue! It's best if you can provide as much context as possible.

## Setting up for development

1. Clone the repo and `cd` into it.
2. Run `npm install` to install the dependencies.
3. Run `npm run build` to ensure everything compiles correctly.
4. The main logic is located inside `src/index.ts`.

## Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Update the documentation if you've changed any behavior.
4. Ensure the test suite passes.
5. Issue that pull request!
